Política de privacidade

Atualizada em 6 de novembro de 2026.

A New Tabs at End não coleta, não transmite, não vende e não compartilha nenhum dado. Tudo o que ela precisa fica no seu navegador.

O que a extensão guarda

Ela guarda duas coisas, ambas no armazenamento de extensões do próprio Chrome:

  • A sua configuração de posicionamento — se links abertos de uma aba em um grupo vão para o fim da janela ou para o fim do grupo. Fica em chrome.storage.sync; se a sincronização do Chrome estiver ativa, o Chrome a leva para os seus outros dispositivos. Essa sincronização é feita pelo Chrome e pela sua conta Google; o autor da extensão nunca tem acesso a ela.
  • A última aba que ela posicionou — um id de aba e um id de grupo, números atribuídos pelo Chrome, para o atalho saber qual aba mover. Fica em chrome.storage.session e é apagada quando o navegador fecha.

Nenhum endereço, título de página, conteúdo de página ou histórico de navegação é guardado.

Por que ela precisa de cada permissão

  • tabs — para saber quando uma aba é criada e movê-la. O Chrome descreve essa permissão como capaz de “ler seu histórico de navegação”, porque ela dá acesso ao endereço das abas abertas. A extensão só verifica se o endereço de uma aba recém-criada ainda está vazio, que é como ela diferencia uma aba que você abriu de uma que o Chrome restaurou. Ela nunca registra nem envia um endereço.
  • tabGroups — para manter uma aba no grupo, ou tirá-la de lá, conforme a sua configuração.
  • storage — para guardar os dois itens acima.

A extensão não consegue ler nem alterar o conteúdo das páginas que você visita.

O que ela não faz

  • Não faz nenhuma requisição de rede: sem analytics, sem telemetria, sem relatórios de erro, sem anúncios.
  • Não carrega código remoto; tudo o que ela executa está no pacote que você instala.
  • Não compartilha nada com terceiros, porque não tem nada a compartilhar.

Este site

Esta página é hospedada no GitHub Pages. Ela não usa cookies, analytics nem scripts de terceiros. O GitHub pode manter logs de servidor comuns, como endereços IP, conforme a Declaração de Privacidade do GitHub.

Mudanças

Se a extensão algum dia passar a tratar dados de outra forma, esta página será atualizada antes de essa versão ser publicada, e a data acima mudará. O histórico completo desta política está no repositório do projeto.

Contato

Dúvidas sobre privacidade são bem-vindas como uma issue no GitHub.
