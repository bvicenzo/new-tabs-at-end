Privacy policy

Last updated on November 6, 2026.

New Tabs at End does not collect, transmit, sell or share any data. Everything it needs stays in your browser.

What the extension stores

It keeps two things, both in Chrome’s own extension storage:

  • Your placement setting — whether links opened from a grouped tab go to the end of the window or to the end of the group. It is kept in chrome.storage.sync, so if Chrome Sync is on, Chrome carries it to your other devices. That sync is done by Chrome and your Google account; the extension’s author never sees it.
  • The last tab it placed — a tab id and a group id, both numbers that Chrome assigns, so the shortcut knows which tab to move. It is kept in chrome.storage.session and erased when the browser closes.

No web address, page title, page content or browsing history is ever stored.

Why it needs each permission

  • tabs — to know when a tab is created and move it. Chrome describes this permission as being able to “read your browsing history”, because it gives access to the address of open tabs. The extension only checks whether a newly created tab’s address is still empty, which is how it tells a tab you opened from one Chrome restored. It never records or sends an address.
  • tabGroups — to keep a tab in its group, or take it out, according to your setting.
  • storage — to keep the two items above.

The extension cannot read or change the content of the pages you visit.

What it does not do

  • It makes no network requests: no analytics, no telemetry, no crash reports, no ads.
  • It loads no remote code; everything it runs is in the package you install.
  • It shares nothing with third parties, because it has nothing to share.

This website

This page is hosted on GitHub Pages. It uses no cookies, analytics or third-party scripts. GitHub may keep standard server logs, such as IP addresses, under the GitHub Privacy Statement.

Changes

If the extension ever starts handling data differently, this page will be updated before that version is published, and the date above will change. The full history of this policy is in the project’s repository.

Contact

Questions about privacy are welcome as an issue on GitHub.
